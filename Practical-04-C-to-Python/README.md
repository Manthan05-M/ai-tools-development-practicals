# Practical 4: C to Python Conversion

## Objective
To convert a simple C program into Python using Google Colab.

## Tool Used
Google Colab

## C Program
```c
#include <stdio.h>
int main() {
    int a = 10, b = 20;
    printf("Sum = %d", a + b);
    return 0;
}
```

## Converted Python Code
```python
a = 10
b = 20
result = a + b
print("Sum =", result)
```

## Output
```text
Sum = 30
```

## Procedure
1. Opened Google Colab.
2. Identified the logic of the C program.
3. Converted the C statements into Python statements.
4. Executed the Python code.
5. Verified the output.

## Result
The C program was successfully converted into Python.

## Conclusion
Learned how to convert basic C programming logic into Python and execute it using Google Colab.
