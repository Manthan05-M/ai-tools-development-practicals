# Practical 3: Tiktokenizer

## Objective
To understand how text is divided into tokens.

## Tool Used
Tiktokenizer

## Procedure
1. Open https://tiktokenizer.vercel.app/
2. Enter a sample English sentence.
3. Observe the generated tokens.
4. Enter a Hindi sentence.
5. Compare the token counts.

## Result
Studied the process of tokenization and observed
how text is converted into tokens.
