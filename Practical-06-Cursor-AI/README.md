# Practical 6: Cursor AI – Ask, Inline Edit and Refactor

## Objective
To understand and use Cursor AI features for asking questions, editing code and improving code structure.

## Tool Used
- Cursor AI

## Features Used

### 1. Ask
The Ask feature helps users understand code and get answers to programming questions.

### 2. Inline Edit
Inline Edit allows users to modify selected code using natural-language instructions.

### 3. Refactor
Refactoring improves code readability and structure without changing its functionality.

## Procedure
1. Opened a project in Cursor AI.
2. Used Ask to understand the code.
3. Used Inline Edit to modify the code.
4. Used Refactor to improve code structure.
5. Reviewed the suggested changes.

## Result
The Ask, Inline Edit and Refactor features of Cursor AI were explored.

## Conclusion
Cursor AI helps developers understand, edit and improve code more efficiently.
